# 实验协议

每个实验只改变一个主要变量，并使用未修改的官方评分器。开发阶段每场景至少 5 次固定种子重复；进入报告的方案建议每场景至少 20 次。

## 必须保存

- 官方基线提交与自研方案提交；
- OS、Python、CUDA、GPU、MuJoCo 渲染后端；
- 场景、seed、参数差异和模型 checkpoint；
- 轨迹 JSON、事件、官方分数、碰撞、耗时、路径长度；
- 成功/失败阶段和失败原因；
- 原始日志，不只保留成功运行。

## 通过门槛

- L1-L4：匹配 `grasp_end success`、离开和到达条件均通过、零碰撞。
- L5：三件对象分别满足上述条件、零碰撞。
- 报告平均分、整任务成功率和 95% 置信区间；单次最好成绩只能作为演示，不能作为结论。
