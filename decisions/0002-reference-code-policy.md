# ADR-0002：隔离第三方与其他参赛者代码

- 状态：accepted
- 日期：2026-07-22
- 决策人：JCIIOT 2026 参赛团队

## 背景

比赛允许公开开源代码和工具，但禁止未公开或需要授权的代码、数据和工具；抄袭会取消成绩。获奖实现需要随名单公开全部代码。当前调研涉及开源研究仓库、受限许可证组件和其他参赛者公开 fork。

## 候选方案

1. 把所有参考仓库直接 vendor 到比赛仓库，按需要复制代码。
2. 只保存网页链接，不下载或固定版本。
3. 本地隔离固定版本 checkout，主仓库只保存 manifest、许可证判断、审计笔记和独立实现。

## 决定

采用方案 3。

- 外部代码保存在被 Git 忽略的 `references/repos/`。
- `references/repositories.json` 固定 URL、commit、许可证初判和用途。
- 调研结论写入 `research/notes/`，不得通过修改第三方 checkout 保存批注。
- 实际采用代码时，只把必要部分通过独立实现或合规移植进入官方允许目录，并保留版权/许可证声明。
- 其他参赛者 fork 只允许诊断比较，禁止复制任何实现。

## 直接禁止

- OK-Robot 中需要单独授权的 AnyGrasp 代码、权重和编译二进制；
- 许可证或来源无法确认的模型、数据和工具；
- 将 MimicGen 非商业代码直接复制、派生或绑定进当前参赛实现，除非先完成书面许可复核；
- 复制其他 JCIIOT 队伍的固定计划、训练脚本、参数或修复代码；
- 通过修改官方 scorer、core、environment 或 task config 取得成绩。

## 后果

- 私有工作仓库不会意外包含数百 MB 第三方源码和历史。
- 每个采用决策需要额外的许可证和接口审计，但能够支撑获奖后公开要求。
- 参考项目更新不会自动改变结论，必须显式更新 commit 和重新审计。
- 从参考方法到比赛实现之间保留清晰的原创开发边界。

- 最终开源方式、仓库许可证或权重分发方式发生变化。
